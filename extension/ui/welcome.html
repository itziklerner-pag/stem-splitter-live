Stem Splitter Live

Take any track your own tab is already playing and pull it apart — vocals, drums, bass and more — on this machine, live, while it plays.

Separation runs a model locally. It has to be fetched a single time, and is then kept on this computer and reused forever.

Check on YouTube now

Opens Despacito in a new tab — a busy mix, which is the interesting case.

This is the only network request this extension ever makes. No audio, no page addresses and no usage data are ever sent anywhere. You can verify it: after this download, everything works with the network off.

  1. Open a YouTube video and let it play as usual.
  2. Click the Stem Splitter Live icon in the toolbar — or press the shortcut. The deck appears under the player.
  3. Mix. Pull the vocal out, solo the drums, shift the key. The deck follows the video; there is no second play button.

Separated audio arrives about three and a half seconds behind the picture, and further behind on a slower machine. That is not a bug being fixed later — the model can only separate sound it has already heard, so the deck is always that far behind. The readout shows exactly how far, measured rather than predicted.
